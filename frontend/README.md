# SAGA Vistoria — Frontend

SPA React para o Sistema de Vistoria Prévia Veicular.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

Aplicação disponível em `http://localhost:5173`

## Build para produção

```bash
npm run build
```

## Tecnologias

- React 18 + TypeScript + Vite
- Tailwind CSS
- TanStack Query
- React Router v6
- signature_pad (assinaturas digitais)
- axios
